# Lumina Outreach

Lumina is an AI-powered cold email outreach platform for sales and marketing teams.
It helps users find leads, write personalized emails, and run automated outreach campaigns.
A big part of the product is deliverability, so it includes warmup, inbox placement, and spam-monitoring features.
It also gives users a unified inbox called Onebox to manage replies from all campaigns in one place.
The platform supports multiple email accounts and helps teams scale outbound without juggling separate tools.
It is mainly built for founders, agencies, and B2B sales teams that want to generate meetings and leads through cold email.
In simple words, Lumina is a tool that automates the full cold-email workflow from prospecting to reply handling.
It is basically an all-in-one outbound sales system focused on personalization, automation, and better inbox results.
